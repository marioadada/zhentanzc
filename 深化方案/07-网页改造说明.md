## 二、页面的三个核心能力

### 2.1 时点分层 —— 这是别的参赛作品做不出来的

页面顶部有「查询时点」选择器。改日期，全站结论切换到对应版本。

**实测对比**（页面验收 B 组）：

| 查询时点 | 生育保险判定 | 依据 |
|---|---|---|
| 2026-02-28 | **不符合** | 厦府规〔2022〕12号 第五十二条：灵活就业人员不参加生育保险 |
| 2026-10-25 | **符合** | 闽医保〔2026〕13号 + 厦医保〔2026〕24号：纳入覆盖范围，0.7% 缴费 |

而且**当前结论旁边直接显示另一时点的答案**：

> 换个时点看，答案会变：
> `0000-01-01 ~ 2026-02-28` → **不符合**
> 依据：厦府规〔2022〕12号《厦门市职工医疗保险实施细则》第五十二条…

### 2.2 结论可自证 —— 每条都能点开核对

判定卡下方是引用块，展开后显示：

```
（分段）@居民医保          厦府规〔2022〕12号          展开原文 ▾
┌──────────────────────────────────────────────┐
│ 第四条 本市行政区域内，未参加职工医保或未按照  │
│ 规定享有其他医疗保障的下列城乡居民依法参加居民医保：│
│ （一）本市户籍的成年居民 …                    │
└──────────────────────────────────────────────┘
来源 ylbz.xm.gov.cn ↗
抓取于 2026-10-24 22:39　证据层级 L1
快照 sha256:e76be654ab7df9ef5fda099c…
```

**注意 `（分段）@居民医保` 这个标识** —— 这就是制度域隔离。同一份文件里职工细则和居民细则条款号撞车（都是"第六条"），加了域标识才能唯一定位。

### 2.3 计算器 —— 参数不硬编码

「灵活就业医保每月要交多少钱？」→ 拖动基数滑块，实时算：

```
灵活就业职工医保 · 月缴费额
灵活就业人员在上年度省平均工资60%—300%范围内自主选择缴费基数
选择缴费基数（4579 ~ 22893 元，七档）
[滑块]  4579 ← 6000 → 22893
月缴费 = 570.00 元
费率 9.5%　依据 厦医保公告 2026年度职工基本医疗保险缴费率
```

费率**从参数表按 `as_of` 取**，不是写死的。改时点到 2027 年，费率自动变 9.35%。

### 3.1 组件与数据字段的对应

| 组件 | 数据来源 | 字段 |
|---|---|---|
| 时点选择器 | 全局 `state.asOf` | 改后重算全部结论 |
| 判定徽章 | `result.verdict` | 七态枚举，固定文案 |
| 依据块 | `result.basis` | 文号 + 条款 + 理由 |
| 要点列表 | `result.extra[]` | 时点版本的补充说明 |
| 时点分层提示 | `result.otherTimepoints[]` | 另一时点的判定 + 依据 |
| 缺失条件 | `result.missing[]` | 可勾选，勾完立刻重算 |
| 引用块 | `result.citations[]` | 文号/条款/原文/URL/抓取时间/哈希 |
| 计算卡 | `result.calc` | 公式/金额/费率/来源/可选区间 |
| 办事抽屉 | `serviceLayer` | 联办/材料/时限/电话/条件 |
| 同步条 | `meta.last_sync` | 数据同步时间 + 统计 |
| 文件列表 | `policies` + `statusCheck` | 文号 + 有效性标注 + 条款数 |
| 制度对比表 | `pickParam()` 按 as_of 取 | 每格带条款引用 |

## 五、这一轮抓到的自身缺陷

| 缺陷 | 后果 | 修法 |
|---|---|---|
| **`ROUTES` 里 `caseId` 写成 `case_id`** | **所有查询静默返回空** —— 路由完全失效但不报错 | 修正字段名。这是本轮最隐蔽的 bug：代码能跑、页面能开、就是没结果 |
| 阶梯参数当二元组读（`value[0]/value[1]`） | 对比表和连续参保计算器抛 `th[1].map is not a function` | 改为两个独立参数 `tier_rates_pct` + `tier_thresholds_months` |
| 引擎未导出 `cases` | 画像页产出空白 | 补 `cases` / `paramTable` / `validityMeta` 导出 |
| **滑块把费率当倍数**（基数 × 9.5） | 显示 95000 元而非 950 元 —— **会让用户看到错数字** | 改为 `基数 × rate / 100`，且费率从参数表取 |
| 条件不全时不跑计算器 | 失业保险金明明能算月标准，却因缺缴费月数而不显示 | 条件不全也跑计算器，能算的部分先给 |
| `district` 被误设为必填 | 浏览器校验拦截提交，画像点了没反应 | 改为可选（原设计本就是可选） |
| 时点用了 UTC 日期 | 本地早上 8 点前显示昨天 | 改用本地日期 |
| HTML 里 3 个坏字符 | 页面出现"有效���政策计算" | 修掉并加检查 |
| 对比表 2027 行写死数字 | 违背"参数不硬编码" | 改为从参数表推导 |

**前两条如果不做真机测试根本发现不了** —— 页面能打开、无报错、只是没结果。

## 七、还差什么（诚实列出）

| 项 | 状态 | 说明 |
|---|---|---|
| 参保承诺制（外地户籍无居住证可参保） | ❌ 未拆条款 | 对"28岁待业外地户籍"这个画像是关键路径，**建议优先补** |
| 跨险种转移接续细则 | ❌ 未拆条款 | 国办发〔2009〕66号、人社部规〔2016〕5号已抓到快照 |

| 居民医保缴费期倒计时 | ⚠️ 部分 | 有"每年 9-12 月"的规则，但没有 2026 年度具体截止日（12-26） |
| 20 题人工盲测 | ⏳ 待组织 | 需要人力 |

**页面已能完整支撑社保线**（职工医保 / 居民医保 / 养老 / 失业 / 生育 / 断缴 / 转移的判定与计算）。
**非社保线（培训、创业、住房、征收）目前是空的** —— 这几条要接入就得再抓一批文件。
