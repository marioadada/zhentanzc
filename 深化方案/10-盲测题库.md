# 10-盲测题库（20 题，带标准答案）

> 生成时间：2026-10-25
> 用途：人工盲测「厦门民生政策侦探」的判定与引用是否可靠。
> 所有标准答案的数字与引用均取自 `policy_db/param_table.json` 与 `policy_db/cases.json`（一手文件自证），不是凭印象写的。

---

## 使用方法

1. 双击打开 `web-参赛版/index.html`
2. 把「输入问题」一栏原样输入搜索框，点「查证政策问题」
3. 对照三件事：
   - **判定**：徽章文字是否等于「期望判定」（七态：符合 / 不符合 / 条件待核验 / 时点不适用 / 未查到可靠依据 / 来源冲突·已裁决 / 来源冲突·待人工）
   - **引用**：点开「依据」里的原文条目，文号 + 条款是否与「期望引用」一致，且原文确实是官方文件的片段
   - **数字**：判定/计算器里出现的金额、比例、月份是否与「标准答案要点」一致
4. 在每题末尾的「盲测记录」勾选 通过 / 不通过，并写一句备注
5. 汇总：20 题中「判定一致 + 引用一致」均满足才算该题通过；**17/20 以上**（85%）视为盲测通过

**时点切换题（第 10 题）**：先用默认时点测一次，再把「查证时点」改成 2026-02-28 测一次，两次结论必须不同——这是本工具的核心卖点（时点分层）。
