### 7.5 人工盲测方案

1. 题目：20 个真实用户问题（覆盖 3 个画像 × 6 类问题 + 2 个陷阱题）
2. 执行：产品输出 → 打乱 → 交给 2 名不懂政策的第三方 + 1 名社保经办/HR
3. 打分口径：每题 3 分制
   - 3 = 结论明确、引用可点开验证、下一步可执行
   - 2 = 结论对但缺一步
   - 1 = 结论含糊或需用户自己再查
   - 0 = 结论错误
4. 指标：**评审者复现率** = 判定为"结论明确可执行"的题数 / 总题数。目标 ≥ 80%
5. 争议项进入人工审查队列；错例直接进回归集

### 7.6 用户纠错闭环设计

| 元素 | 行为 |
|---|---|
| "这条错了"按钮 | 挂在每条结论卡片上，弹窗预填：引用哪个条款、哪里不对（可选：条款已失效 / 结论与实际不符 / 引用打不开 / 表述误导） |
| "条件已变"按钮 | 挂在缺失条件上，用户可补充条件并立即重算 |
| 错例日志 | 存 `corrections.jsonl`：`{ts, case_id, verdict, citation, user_complaint, snapshot_hash}` |
| 转化 | 错例 → 回归集用例（人工确认后）→ 断言 |

### 8.3 组件规格表（每个组件对应哪个数据字段）

| 组件 | 数据来源 | 关键字段 | 状态处理 |
|---|---|---|---|
| **时点选择器** | 全局 `as_of` | `as_of`（默认今日） | 切换后所有结论重算 |
| **证据概览条** | `cases[].citations` 聚合 | `layer`、`doc_number`、`fetched_at` | 0 条 → 隐藏；1 条 → 显示"仅1条依据，建议谨慎" |
| **判定徽章** | `result.verdict` | 7 态枚举 | 每态一套色 + 固定文案，**禁止用"部分匹配"这类歧义词** |
| **依据引用块** | `result.citations[]` | `doc_number`、`clause_no`、`quote`、`url`、`fetched_at`、`text_sha256` | 折叠默认；点击展开全文 + 哈希 + 打开原文按钮 |
| **时点分层提示** | `detail.other_timepoints[]` | `window`、`verdict`、`basis` | 0 个 → 隐藏；≥1 个 → 必显 |
| **缺失条件清单** | `result.missing[]` | `field`、`label`、`why` | 每项必须带 `why`（为什么问这个） |
| **计算卡** | `detail.calculation` | `formula`、`amount`、`rate`、`rate_source`、`available_range` | `needs_input` → 显示可选区间而非数字；查不到参数 → 显示"未找到适用时点参数"，**不猜** |
| **下一步动作** | `result.next_action` | 文本 | 必显，不可为空 |
| **纠错入口** | — | `case_id`、`citation` | "这条错了" / "条件已变" |
| **样本/实时标识** | `data_mode` 字段 | `sample` / `live` / `cached` | 由**数据字段**驱动渲染，非文案 |

### 8.4 我的画像页（辅助入口）

保留交接包现有的简易版/详尽版双模式，但改造三处：

1. **标签三态扩展为四态**：原 `confirmed` / `unknown` / `not_applicable` → 增加 `conflict`（用户填了矛盾信息，如"已参保职工医保"又选"未参保"）
2. **推荐项走同一判定引擎**：画像命中的政策，用 `engine.judge()` 求值，与查证页同一口径、同一 citation
3. **推荐卡片结构与查证页卡片统一**：同一套判定徽章、引用块、缺失条件组件

新增字段（社保线必需，来自本轮验证的硬条件）：

### 8.6 边界状态清单

| 状态 | 表现 |
|---|---|
| 空查询 | 不发请求，提示"试着问：待业该交哪种医保" |
| 无匹配判定式 | **不得**显示空白。显示"未检索到适用的一手依据"+ 已检索的源清单 + 官方自查入口（12333/12345/税务大厅） |
| 引用链接失效 | 显示"来源链接当前不可访问" + 本地快照哈希 + 抓取时间 |
| 快照与线上不一致 | 显示"该文件自 YYYY-MM-DD 起可能已修改"（对比二次抓取哈希） |
| 政策已废止 | 判定自动降级为 `NO_EVIDENCE`，并显示"该文件已列入废止目录" + 替代文件 |
| 参数查不到 | 显示"未找到适用时点参数"，**不给数字** |
