## 一、一句话定位

**它不告诉你"政策是什么"，它告诉你"你这种情况，今天该按哪一条办"。**

政策侦探是一个面向普通市民的民生政策判定工具：用户用一句大白话提问，系统返回 **判定 + 依据原文 + 下一步**，每一条结论都能点开验证到官方原文、一键跳回官方源页面。

---

## 二、要解决的真实问题

1. **信息很多，答案很少。** 政策文件公开可得，但普通人面对的是"10 条蓝链，自己判断哪条适用、哪条过期、是不是他这种情况"。网上的问答帖、短视频大多凭印象，错一句就是真金白银的损失。
2. **政府的职能平台是分割的。** 医保局、人社局、税务局、政务 App 各自为政，一个问题要在多个入口之间跳转，群众无所适从。没有哪个统一入口能"就我的情况"给一个可信结论。
3. **时点会骗人。** 厦门 2026-03-01 实施长护险、2026-10 发布 2027 年度居民医保标准——不区分时点的工具，会在政策切换点给错答案。
4. **失效文件还在流传。** 网上大量引用已标注"失效"的旧规却无人标注，普通人无从分辨。

> 做这个产品的初衷很朴素：在网上经常看到各种政策求助，而各部门的平台又彼此割裂、很难在一个地方问清楚。先做一个"政策侦探"把厦门跑通；如果成熟，再把城市一个个连起来，助力民生、做生态融合。

---

## 三、核心能力

- **七态判定**：符合 / 不符合 / 条件待核验 / 时点不适用 / 未查到可靠依据 / 来源冲突·已裁决 / 来源冲突·待人工。拒绝"可能可以"式含糊结论。
- **依据原文可回溯 + 一键跳官方页**：每条结论挂 文号 + 条款号 + 原文全句 + 抓取时间 + 快照哈希；引用块展开后底部带官方源链接（如 `xm.gov.cn`、`ylbz.xm.gov.cn`、`hrss.xm.gov.cn`），新标签打开。引用可回溯率 **100%**（断言逐条校验引用是快照正文真实子串）。
- **时点分层**：全站带"查询时点"一等公民；同一问题切日期，结论随版本切换，并提示另一时点的答案。
- **失效文件硬拦截**：官方"有效性"字段纳入判定链；失效文件不入库、引用时硬闸门拒绝、旧结论改引仍有效的上位文件。
- **全文检索 + 领域词典**：对 **249 条**官方条款原文做 BM25 检索，配 100+ 社保领域词典；真实问法 Top-3 召回 91%、Top-1 精确 73%、14 个自由问法零漏召。

## 四、技术架构

**构建期（可证伪的源头）**
直连厦门官方一手站抓取 → 内容归一化（剥离动态时间戳 / 随机 token / 当天星期几，避免误报变更）→ 结构化抽取条款与参数 → 生成数据包（`policy_data.js` / `search_index.js`）→ 跑 **214 条 Python 自动化断言**，断言红了就拒绝发布。

**页面端（纯静态、零后端）**
`index.html` + 本地 JS，无需服务器、无需浏览器后端。判定引擎、`BM25` 检索、引用渲染全部在浏览器内完成。

**两个关键设计取向**
- **离线可证伪**：每一条结论都带着"快照哈希 + 原文片段"，不依赖外网活不活。
- **一键回官方源**：引用块里的官方链接，是用户从"本工具的判定"走向"官方权威原文"的桥。

## 六、和"普通搜索 / 大模型问答"的差别

| | 普通搜索 | 大模型问答 | 政策侦探 |
|---|---|---|---|
| 给什么 | 一堆链接，自己判断 | 一段通顺的话 | 判定 + 原文依据 + 下一步 |
| 可验证 | 要自己点进去核 | 常给不出出处 | 每条挂文号/条款/哈希，点开即核 |
| 时点 | 无 | 大多数无 | 一等公民，切日期换结论 |
| 失效文件 | 照常推 | 照常编 | 硬拦截，不引用失效依据 |
|  hallucination 风险 | 低 | 高 | 零（结论必须落在快照原文） |

## 七、诚实的边界

**已完整支撑**：职工医保 / 居民医保 / 养老 / 失业 / 生育 / 断缴 / 转移接续 的判定与计算。

**尚未接入**：拆迁征收、职业培训补贴、创业补贴等线——这些还没有一手源接入，产品里明确是空的，不假装能答。

**不做什么**：不替代主管部门的资格认定与审批结论；缺条件时明确说缺什么，不猜。

**新鲜度**：数据是构建期抓取的冻结快照，链接是抓取时写死的。当前更新文本库需要人工重跑抓取流水线，没有页面自身定时自动刷新。这是从"demo"走向"真·平台"必须补齐的下一步（见下）。

---

## 八、生态愿景：从厦门，到民生融合

现在的形态是"一城一库"的静态判定工具。它的真正价值不在这一版界面，而在**可复制的范式**：

1. **多城联网**：把"抓取一手源 → 抽取条款 → 七态判定 → 引用可回溯"这套管线，套到任意城市。每个城市一个数据包，统一入口查询。
2. **职能融合**：以"市民的一个问题"为入口，穿透医保 / 人社 / 税务 / 政务的多平台割裂，让普通人只问一次。
3. **可信底座**：每条结论都带官方源链接与快照指纹——这是 AI 答政策最稀缺的东西：**可证伪、可审计、可追责**。
4. **自动同步（roadmap）**：定时抓取 + 内容指纹变更检测 + 自动重建 + 断言卡口。这一步补齐后，产品才真正从"参赛 demo"升级为可持续运营的民生基础设施。

**一句话**：把分散在各部门的政策，变成普通人能问、能信、能核的一个答案。
