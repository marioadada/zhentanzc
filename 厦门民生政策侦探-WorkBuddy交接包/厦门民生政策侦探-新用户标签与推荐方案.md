# 新用户标签与政策推荐方案

## 1. 两种画像模式

### 简易版：约 30 秒

适合第一次使用，只问 5 项：

1. 年龄段：16—24、25—34、35—49、50—59、60 岁以上
2. 当前状态：在校、应届毕业、就业、待业/失业、灵活就业、个体经营、退休、其他
3. 学历：高中及以下、大专、本科、硕士及以上、不确定
4. 所在地：厦门哪个区；是否厦门户籍；是否在厦门租房/居住
5. 当前最想解决的 1—3 项：找工作、培训考证、住房、创业、社保医保、子女教育、养老、困难救助、劳动维权

简易版只输出“政策方向推荐”，不做精确资格判断。每张卡片必须注明：需要补充哪些信息。

### 详尽版：约 2—3 分钟

在简易版基础上，按用户选择动态追问，不展示无关问题。

**就业/待业**：毕业年份、是否全日制、是否办理失业登记、是否缴过厦门社保/失业保险、离职原因、可接受工作区域。

**培训/考证**：目标工种、证书等级、是否已有证书、是否参加过同类补贴、可参加时间、线上/线下偏好。

**住房**：所在区/街道、来厦时间、租住方式、本人及家庭住房情况、家庭收入区间、是否接受保障性租赁住房。

**创业**：创业意向、业务方向、公司/个体户状态、注册时间和所在区、是否正常经营、员工人数、是否已享受同类政策。

**人才**：毕业院校类别、毕业时间、来厦时间、单位性质、是否在厦缴社保、是否已入职。

**救助/医疗/养老**：家庭成员、收入区间、医保状态、特殊身份或困难认定情况。

**征收拆迁**：所在区、街道/村居、项目名称/公告编号、房屋性质、是否收到正式公告。

详尽版才允许输出“条件初步匹配”，仍不输出“最终符合”。

## 2. 标签分层

每个标签记录三种状态：

- **已确认**：用户明确填写或选择；
- **待核验**：可能影响资格，但用户未提供；
- **不适用/未选择**：用户明确表示与当前目标无关。

示例：

```json
{
  "age_group": {"value":"25-34", "status":"confirmed"},
  "employment_status": {"value":"unemployed", "status":"confirmed"},
  "xm_unemployment_registration": {"value":null, "status":"unknown"},
  "graduation_year": {"value":null, "status":"unknown"},
  "goals":["job","training","housing"]
}
```

## 3. 推荐层级

### 第一层：当前行动

用户已表达目标，且有官方服务入口。例如待业用户先看失业登记、公共就业服务和岗位匹配。

### 第二层：可能相关

画像命中政策人群或场景，但硬条件未核验。例如本科待业用户可能关注职业培训、新引进人才政策。

### 第三层：条件触发

只有关键硬条件已经确认，才出现。例如确认“已在厦门单位就业并缴社保”后，再进入新引进人才补贴核验。

## 4. 推荐卡片标准

每张卡片显示：

- 政策/服务名称
- 推荐层级
- 为什么推荐：命中的标签
- 还缺什么：决定性条件
- 可能获得：补贴、服务或办理资格（不得夸大金额）
- 官方来源、发布机关、日期和有效状态
- 去查证按钮
- 暂不关注按钮

## 5. 28 岁本科待业租房示例

### 简易版结果

优先显示：

1. 厦门公共就业服务与失业登记
2. 职业培训和技能提升项目
3. 厦门岗位与人才招聘
4. 住房保障/保障性租赁住房线索

条件性显示：

5. 新引进人才生活补贴：需毕业年份、院校类别、来厦时间、入职和社保
6. 创业扶持：需先确认是否有创业计划

不显示：拆迁、养老、残疾人、低保等无目标或无事实依据的政策。

### 详尽版追问后

- 若已办理失业登记：提高就业援助和培训推荐级别；
- 若未登记且想考证：先推荐登记/公共就业服务，再查当期培训目录；
- 若已入职厦门单位并缴社保：启动人才补贴核验；
- 若仍待业：人才生活补贴保持“条件性候选”，不展示为可申请；
- 若租住保障性租赁住房且家庭条件符合：进入住房政策核验；
- 若选择创业：才展示创业启动、场地、带动就业和担保贷款等政策。

## 6. 推荐算法约束

推荐分数不由年龄决定，采用：

- 用户目标匹配 35%
- 官方硬条件已确认 30%
- 身份/登记状态 20%
- 地区匹配 10%
- 年龄/职业软匹配 5%

任何政策必须满足：

- 至少一个官方来源；
- 有明确适用人群或服务对象；
- 有有效状态或标记为“时效待核”；
- 未确认硬条件时只能是“可能相关”；
- 来源冲突时不能进入“条件初步匹配”。

## 7. 产品验收

- 新用户可在 30 秒内完成简易画像；
- 详尽版只追问与目标相关的问题；
- 推荐结果能解释命中标签和缺失条件；
- 同一用户切换目标后，推荐顺序会变化；
- 用户明确不关注的主题不再出现在首屏；
- 所有推荐均能进入证据核查页；
- 推荐结果不把样本数据伪装成实时政策。
