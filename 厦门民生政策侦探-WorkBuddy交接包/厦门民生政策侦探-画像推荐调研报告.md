# 厦门民生政策侦探：画像推荐调研报告（修订版）

## 结论

画像推荐不能由“年龄 + 职业”直接推断政策。厦门官方人社站点把服务拆成“就业困难人员、创业、技工教育、职业培训、技能鉴定、社会保障、人才服务”等栏目；同一用户可能同时符合多个栏目，也可能因注册时间、社保缴费、证书工种、是否重复享受等条件被排除。

因此推荐模块应采用 **两阶段判断**：

1. **候选发现**：根据画像推荐“可能相关”的政策主题；
2. **资格核验**：补问决定性条件，并把每条条件对应到官方原文。没有核验前不得显示“你符合”。

## 已核实的官方线索

### 厦门市人社局服务分类

官方首页明确提供：

- 就业困难人员
- 创业
- 技工教育
- 职业培训
- 技能鉴定
- 社会保障
- 人才服务

官方入口：[厦门市人社局](https://hrss.xm.gov.cn/)、[网上办事](https://app.hrss.xm.gov.cn/)、[就业创业服务园地](https://hrss.xm.gov.cn/ldl/?zsno=%E5%B0%B1%E4%B8%9A%E5%88%9B%E4%B8%9A)。

### 2026 年职业培训线索

人社局站点在 2026-09-30 发布“学技能，学费有补贴！第四季度项目制培训计划来了”的通知线索。这说明培训推荐必须包含 **季度/报名期**，不能只根据职业静态推荐“免费培训”。

### 创业政策线索

厦门就业创业政策搜索结果显示，创业相关政策至少涉及：一次性创业项目启动补助、创业场地补贴、创业带动就业奖励、创业培训补贴。公开政策摘要还出现“成立时间、正常经营时间、申请时仍在经营”等限制条件，因此画像中必须询问企业/个体户成立时间和经营状态。

### 高校毕业生与人才政策线索

厦门高校毕业生政策指南涉及校园招聘、求职创业补贴、就业见习等；新引进人才生活补贴的公开办事指南包含“引进时间、厦门辖区企事业单位/社会组织、人才身份”等条件。故“22 岁”本身不能触发人才补贴推荐，必须先确认是否应届、是否在厦门新引进、单位性质和引进日期。

## 画像字段与决策作用

| 字段 | 可用于发现什么 | 不能单独推出什么 | 必须补问 |
|---|---|---|---|
| 年龄段 | 青年就业、退休养老、部分培训项目 | 不等于应届生或困难人员 | 学籍/毕业时间、就业状态 |
| 所在区 | 区级住房、征收、社区救助、培训班 | 不等于具有区级资格 | 街道/社区、项目名称 |
| 身份 | 选择政策人群栏目 | 不等于满足政策全部条件 | 是否有登记、证明或平台状态 |
| 职业/行业 | 培训工种、行业扶持、就业服务 | 不等于目录内急需工种 | 想考的工种、证书等级 |
| 企业/个体户 | 创业补助、场地、带动就业 | 不等于“首次创业” | 注册日期、经营状态、社保、雇员 |
| 证书 | 技能鉴定、取证培训 | 不等于可领补贴 | 证书类型、等级、发证机构、是否已领 |
| 住房/征收情况 | 住房保障、征收公告 | 不得推算个人补偿 | 项目公告、房屋性质、安置方案 |

## 推荐规则：政策级“必要条件”

每条政策进入推荐库前，必须结构化为：

```json
{
  "policy_id": "xm-hr-...",
  "topic": "创业补贴",
  "authority": "厦门市人力资源和社会保障局",
  "source_url": "官方原文链接",
  "source_level": "A/B/C",
  "effective_status": "active/uncertain/expired",
  "hard_conditions": [
    {"field":"business_registered_at","operator":"within_years","value":3,"evidence":"原文条款"},
    {"field":"business_operating","operator":"eq","value":true,"evidence":"原文条款"}
  ],
  "soft_signals": ["创业意向","个体经营者"],
  "exclusions": ["同类补贴已享受"],
  "ask_next": ["注册时间","是否正常经营","所在区"]
}
```

只有 `soft_signals` 命中时显示“可能相关”；所有 `hard_conditions` 核实通过后，才显示“条件初步匹配”。任一硬条件未知，显示“需要核验”，不能显示“符合”。

## 四类画像的精确推荐流程

### 1. 应届毕业生 / 22 岁 / 未就业

**先推荐候选主题**：求职创业补贴、就业见习、校园招聘、职业培训、创业扶持。

**必须追问**：毕业年份、学校/学历、是否属于困难或特定人群、是否已就业/缴社保、是否准备创业。

**禁止直接推荐**：新引进人才生活补贴。除非确认已在厦门单位就业且满足引进时间和人才条件。

### 2. 31 岁 / 灵活就业 / 想考证

**先推荐候选主题**：职业培训、技能鉴定、急需紧缺工种目录、灵活就业社保服务。

**必须追问**：计划考的具体工种和等级、是否在目录内、是否已参加同类培训、当前就业/失业登记状态。

**禁止直接写“免费培训”**：培训是否免费取决于项目、季度、对象和名额；只能写“可能存在补贴项目，需查当前班次”。

### 3. 失业人员 / 46 岁

**先推荐候选主题**：就业困难人员认定、职业培训、就业援助、岗位匹配、社保相关服务。

**必须追问**：是否办理失业登记、是否被认定就业困难人员、失业时长、是否有劳动能力、所在区。

**禁止直接推断**：年龄达到某个区间就属于就业困难人员。

### 4. 58 岁 / 村居征收

**先推荐候选主题**：项目征收公告、补偿方案、安置方案、养老和社会保障衔接。

**必须追问**：区、街道/村居、项目名称或公告编号、房屋性质、户籍/居住情况、是否收到正式公告。

**禁止做的事**：用年龄、户籍和面积估算最终补偿金额；使用别的区或别的项目的补偿标准。

## 推荐排序的改进

原先“年龄 40%”权重过高，容易造成误导。调整为：

- 官方硬条件已确认：50%
- 关注目标匹配：20%
- 身份/登记状态匹配：15%
- 地区和项目匹配：10%
- 职业或行业软匹配：5%

年龄只作为条件字段之一，不再单独作为高权重推荐依据。若硬条件尚未确认，最高只能标记“候选”，不能排到“优先办理”。

## 推荐卡片必须展示

- **推荐级别**：候选 / 需要核验 / 条件初步匹配
- **推荐原因**：具体命中了哪些画像字段
- **未确认条件**：逐项列出
- **排除条件**：哪些情况可能不适用
- **政策时间**：发布日期、有效状态、报名期（如有）
- **官方原文**：链接和关键条款
- **下一步**：补充信息或进入官方办理入口

## 参赛版的真实演示设计

同一画像做三次查询，证明系统不会乱推荐：

1. **22 岁应届毕业生 + 想创业**：展示创业扶持和求职创业政策，并追问毕业年份、注册状态。
2. **31 岁灵活就业 + 想考证**：展示技能培训候选项，追问工种、等级、目录和重复享受。
3. **58 岁村居征收**：不显示补偿金额，要求项目公告和所在区，再进入项目证据检索。

每次录屏都要展示：命中的字段、缺失条件、官方来源和“未确认不下结论”。

## 上线前的必要工作

1. 为每条政策建立结构化条件和证据摘录；
2. 对每个政策记录发布日期、有效状态和报名期；
3. 每个推荐结果至少绑定一个 A/B 级官方来源；
4. 建立“政策失效/来源打不开/条件冲突”的状态；
5. 为用户提供“纠正画像”和“我不符合此条件”反馈；
6. 推荐库更新后重新计算相关性，不能永久缓存旧结果。

## 最终判断

画像推荐值得做，但它不是简单的推荐算法，而是一个 **政策条件匹配和缺失信息追问系统**。参赛版可先覆盖人社高频政策，使用 10—20 条人工核验过的政策卡片；全量民生政策必须在建立来源、版本和条件库后逐步扩展。
